## 作用

后台守护仅适用于 Windows，默认关闭。开启后，青简输入服务意外退出时会自动重新启动，通常约一至两秒后恢复；连续退出时会逐步延长重试间隔，最长为三十秒。

若守护程序也退出，Windows 通常会在下一次每分钟检查时重新启动它。系统休眠、注销或计划任务被禁用期间不保证恢复时间。

后台守护不会修复程序文件缺失、服务卡住或输入法注册损坏。遇到这些情况仍需修复安装，或按[遇到问题](feedback.md)提交日志。手动结束输入服务后，它也会重新启动；若需停止自动恢复，请先暂停守护。

## 开启与暂停

- 开启：在 Windows 开始菜单找到「青简 → 开启后台守护」。开启后在当前账户登录时自动运行。
- 暂停：选择「青简 → 暂停后台守护」。暂停会保留已运行的输入服务，可继续正常输入；之后不会自动恢复服务或守护。
- 继续：再次选择「开启后台守护」。

升级会保留守护原有的开启或暂停状态；卸载会删除此安装创建的守护任务。其他 Windows 账户需各自开启。macOS 与 Linux 暂无此功能。

守护不读取输入内容、API 密钥或学习记录，也不会发送网络请求。常驻守护只监看本次登录会话中属于当前安装的输入服务。
